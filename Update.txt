URL=https://get.smoredboard.com/update
Required=true
Changes=
- Added the SmoredBoard APO Driver BETA, allowing you to play sounds ON your mic, no virtual mic needed, with significantly lower latency! (off by default, still testing this to make sure it works well)
- Fixed error where soundsnap would record a multichannel file, then the SmoredBoard would be unable to play it
- Fixed mp4 to mp3 conversion for mp4s with more than 2 channels
- Added a BETA update option so you can try out updates and new features faster
- Improved fade out/in effect to not cause audio clicking issues and such
- Added option for SmoredBoard to run minimized on startup
- Added way to move Profiles Directory to another location, copying all sounds and profiles
- SmoredBoard now stays on top of task bar always
- Fixed 403 error on downloading sounds from Myinstants
- Improved Sound Editor, to make it easier to use and more intuitive
- Significantly Reduced RAM usage (around 50% on average)
- Fixed some bugs
